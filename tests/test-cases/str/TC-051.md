# TC-STR-051 (TC-051): Kiểm tra nối chuỗi khi First number để trống

## Requirement ID
FR-STR-01

## Module / Test type / Technique
Str / Boundary, Functional / Medium Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | (để trống) |
| Second number | 999 |
| Operation | Concatenate |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Để trống First number.
4. Nhập 999 vào Second number.
5. Chọn Operation = Concatenate.
6. Nhấn Calculate.

## Expected result
Answer hiển thị 999. Không hiển thị lỗi.

## Status / Related bugs
Not Run / None
