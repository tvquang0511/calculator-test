# TC-STR-044 (TC-044): Kiểm tra nối chuỗi có số 0 đứng đầu (Leading Zero)

## Requirement ID
FR-STR-01

## Module / Test type / Technique
Str / Positive, Functional / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 01 |
| Second number | 05 |
| Operation | Concatenate |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 01 vào First number.
4. Nhập 05 vào Second number.
5. Chọn Operation = Concatenate.
6. Nhấn Calculate.

## Expected result
Answer hiển thị 0105. Không bị mất số 0 đứng đầu.

## Status / Related bugs
Not Run / None
