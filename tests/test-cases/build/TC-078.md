| Trường dữ liệu | Giá trị |

| First number | 10 |
| Second number | 2 |
| Operation | Subtract |

1. Mở trang Basic Calculator.
2. Chọn Build = 8.
3. Nhập 10 vào First number.
4. Nhập 2 vào Second number.
5. Chọn Operation = Subtract.
6. Nhấn Calculate.

So sánh với Prototype (10 - 2 = 8): Build 8 hoán đổi thành 2 - 10 và cho ra kết quả -8.
