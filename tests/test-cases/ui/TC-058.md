# TC-UI-058 (TC-058): Kiểm tra bật/tắt Integers only sau khi đã có kết quả tính

## Requirement ID
FR-UI-02

## Module / Test type / Technique
Ui / Functional, UI / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 11 |
| Second number | 4 |
| Operation | Divide |
| Integers only | Toggle from Unchecked to Checked |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 11 vào First number.
4. Nhập 4 vào Second number.
5. Chọn Operation = Divide.
6. Bỏ tích Integers only.
7. Nhấn Calculate.
8. Quan sát Answer (2.75).
9. Tích chọn Integers only.

## Expected result
Tại Step 7: Answer hiển thị 2.75.
Tại Step 9: Answer lập tức đổi thành 2 mà không cần bấm lại Calculate.
