# TC-UI-056 (TC-056): Kiểm tra Integers only = ON với kết quả số thập phân âm

## Requirement ID
FR-UI-02

## Module / Test type / Technique
Ui / Positive, Boundary / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | -7 |
| Second number | 2 |
| Operation | Divide |
| Integers only | Checked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập -7 vào First number.
4. Nhập 2 vào Second number.
5. Chọn Operation = Divide.
6. Tích chọn Integers only.
7. Nhấn Calculate.

## Expected result
Answer hiển thị -3 (theo cơ chế parseInt('-3.5')).

Not Run / None
