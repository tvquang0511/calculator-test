# TC-UI-080 (TC-080): Kiểm tra trạng thái UI trong quá trình tính toán (Spinner & Lock button)

## Requirement ID
FR-UI-01

## Module / Test type / Technique
Ui / UI, Functional / Low Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 50 |
| Second number | 50 |
| Operation | Add |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 50 vào First number, 50 vào Second number, chọn Add.
4. Nhấn Calculate và quan sát ngay lập tức giao diện.

## Expected result
Trong khoảng thời gian tính toán: Biểu tượng waiting.gif hiển thị cùng dòng chữ 'Calculating ...', trường Answer tạm ẩn, nút Calculate và Clear bị disabled. Sau đó trở lại bình thường và hiển thị Answer = 100.
