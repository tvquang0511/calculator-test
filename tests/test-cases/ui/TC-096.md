# TC-UI-096 (TC-096): Kiểm tra trường Answer là ReadOnly

## Requirement ID
FR-UI-02

## Module / Test type / Technique
UI / Security

## Preconditions
- Basic Calculator page is accessible.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 1 |
| Second number | 1 |
| Operation | Add |
| Integers only | Unchecked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập `1` vào First number.
4. Nhập `1` vào Second number.
5. Chọn Operation = Add.
6. Tích/Bỏ tích Integers only: Unchecked.
7. Nhấn Calculate.

## Expected result
Trường Answer không thể focus hoặc nhập liệu
