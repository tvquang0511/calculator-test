# TC-UI-069 (TC-069): Kiểm tra chức năng nút Clear sau khi tính toán thành công

## Requirement ID
FR-UI-01

## Module / Test type / Technique
Ui / Functional, UI / Medium Priority

## Preconditions
- Answer is 70, Integers only is checked.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| Nhấn nút Clear sau khi có Answer | 70 và Integers only đang Checked |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 50 vào First number, 20 vào Second number.
4. Tích chọn Integers only.
5. Nhấn Calculate để Answer hiển thị 70.
6. Nhấn nút Clear.

## Expected result
Trường Answer bị xóa rỗng (''). Checkbox Integers only tự động uncheck. First number và Second number vẫn giữ nguyên.
