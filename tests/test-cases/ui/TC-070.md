# TC-UI-070 (TC-070): Kiểm tra chức năng nút Clear sau khi có lỗi hiển thị

## Requirement ID
FR-UI-01

## Module / Test type / Technique
Ui / Functional, UI / Medium Priority

## Preconditions
- Error message is visible.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| Dữ liệu | Nhấn Clear khi đang có thông báo lỗi hiển thị |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập abc vào First number, 10 vào Second number.
4. Nhấn Calculate để xuất hiện lỗi 'Number 1 is not a number'.
5. Nhấn nút Clear.

## Expected result
Thông báo lỗi đỏ bị xóa rỗng.

Not Run / None
