# TC-UI-055 (TC-055): Kiểm tra Integers only = ON với kết quả thập phân dương sát số nguyên trên

## Requirement ID
FR-UI-02

## Module / Test type / Technique
Ui / Boundary, Functional / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 7.99 |
| Second number | 0 |
| Operation | Add |
| Integers only | Checked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 7.99 vào First number.
4. Nhập 0 vào Second number.
5. Chọn Operation = Add.
6. Tích chọn Integers only.
7. Nhấn Calculate.

## Expected result
Answer hiển thị 7 (xử lý cắt đuôi parseInt('7.99')).

Not Run / None
