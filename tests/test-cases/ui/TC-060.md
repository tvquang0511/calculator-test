# TC-UI-060 (TC-060): Kiểm tra hiển thị lại Integers only khi chuyển từ Concatenate sang Add

## Requirement ID
FR-UI-02

## Module / Test type / Technique
Ui / Functional, UI / Medium Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| Dữ liệu | Operation thay đổi từ Concatenate sang Add |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Chọn Operation = Concatenate (checkbox bị ẩn).
4. Đổi Operation = Add.

## Expected result
Checkbox integerSelect và nhãn Integers only hiển thị trở lại bình thường và cho phép người dùng thao tác.

## Status / Related bugs
Not Run / None
