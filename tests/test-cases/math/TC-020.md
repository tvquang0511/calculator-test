# TC-MATH-020 (TC-020): Kiểm tra phép trừ số 0 cho một số dương

## Requirement ID
FR-MATH-02

## Module / Test type / Technique
Math / Boundary, Functional / Medium Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 0 |
| Second number | 67 |
| Operation | Subtract |
| Integers only | Unchecked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 0 vào First number.
4. Nhập 67 vào Second number.
5. Chọn Operation = Subtract.
6. Nhấn Calculate.

## Expected result
Answer hiển thị -67.
