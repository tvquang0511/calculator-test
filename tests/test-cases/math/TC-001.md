# TC-MATH-001 (TC-001): Kiểm tra phép cộng hai số nguyên dương

## Requirement ID
FR-MATH-01

## Module / Test type / Technique
Math / Positive, Functional / High Priority

## Preconditions
- Basic Calculator page is accessible.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 25 |
| Second number | 15 |
| Operation | Add |
| Integers only | Unchecked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 25 vào First number.
4. Nhập 15 vào Second number.
5. Chọn Operation = Add.
6. Bỏ tích Integers only.
7. Nhấn Calculate.

## Expected result
Answer hiển thị 40. Không có thông báo lỗi hiển thị.
