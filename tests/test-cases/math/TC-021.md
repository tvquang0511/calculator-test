## Requirement ID
FR-MATH-02

## Module / Test type / Technique
Math / Boundary, Functional / Medium Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 99999999 |
| Second number | 11111111 |
| Operation | Subtract |
| Integers only | Unchecked |

2. Chọn Build = Prototype.
3. Nhập 99999999 vào First number.

5. Chọn Operation = Subtract.
6. Nhấn Calculate.

## Expected result
Answer hiển thị 88888888.
