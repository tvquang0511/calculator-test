# TC-MATH-041 (TC-041): Kiểm tra phép chia một số cho 0 (Division by zero)

## Requirement ID
FR-MATH-05

## Module / Test type / Technique
Math / Negative, Boundary / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 15 |
| Second number | 0 |
| Operation | Divide |
| Integers only | Unchecked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 15 vào First number.
4. Nhập 0 vào Second number.
5. Chọn Operation = Divide.
6. Nhấn Calculate.

## Expected result
Thông báo lỗi màu đỏ hiển thị: 'Divide by zero error!'. Không hiển thị kết quả Answer.

## Status / Related bugs
Not Run / None
