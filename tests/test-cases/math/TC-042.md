# TC-MATH-042 (TC-042): Kiểm tra phép chia 0 cho 0 (0 / 0)

## Requirement ID
FR-MATH-05

## Module / Test type / Technique
Math / Negative, Boundary / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 0 |
| Second number | 0 |
| Operation | Divide |
| Integers only | Unchecked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 0 vào First number.
4. Nhập 0 vào Second number.
5. Chọn Operation = Divide.
6. Nhấn Calculate.

## Expected result
Thông báo lỗi màu đỏ hiển thị: 'Divide by zero error!'. Không thực hiện tính toán.

## Status / Related bugs
Not Run / None
