# TC-VAL-067 (TC-067): Kiểm tra Input Validation khi nhập chuỗi toàn khoảng trắng (Whitespace)

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Negative, Validation, Error Guessing / Medium Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | '   ' |
| Second number | 8 |
| Operation | Add |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập các dấu cách '   ' vào First number.
4. Nhập 8 vào Second number.
5. Chọn Operation = Add.
6. Nhấn Calculate.

## Expected result
Cần xác nhận requirement: JS coi '   ' là 0 và tính ra 8. Kỳ vọng chuẩn là báo lỗi 'Number 1 is not a number'.
