# TC-VAL-063 (TC-063): Kiểm tra Input Validation khi cả hai trường đều là chữ cái

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Negative, Validation / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | aaa |
| Second number | bbb |
| Operation | Subtract |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập aaa vào First number.
4. Nhập bbb vào Second number.
5. Chọn Operation = Subtract.
6. Nhấn Calculate.

## Expected result
Hiển thị thông báo lỗi màu đỏ: 'Number 1 is not a number' (kiểm tra First number trước).

## Status / Related bugs
Not Run / None
