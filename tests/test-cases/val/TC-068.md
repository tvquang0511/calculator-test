# TC-VAL-068 (TC-068): Kiểm tra giới hạn độ dài ký tự của trường input (Maxlength = 10)

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Boundary, Validation / Medium Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| Dữ liệu | Nhập 13 ký tự: 1234567890123 |

## Test steps
1. Mở trang Basic Calculator.
2. Nhập chuỗi 1234567890123 vào First number.
3. Quan sát giá trị lưu lại trong ô input.

## Expected result
Ô First number chỉ nhận tối đa đúng 10 ký tự: 1234567890. Không cho phép gõ thêm ký tự thứ 11.

Not Run / None
