# TC-VAL-064 (TC-064): Kiểm tra Input Validation với ký tự đặc biệt

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Negative, Validation / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | @#$% |
| Second number | 5 |
| Operation | Multiply |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập @#$% vào First number.
4. Nhập 5 vào Second number.
5. Chọn Operation = Multiply.
6. Nhấn Calculate.

## Expected result
Hiển thị thông báo lỗi màu đỏ: 'Number 1 is not a number'.

## Status / Related bugs
Not Run / None
