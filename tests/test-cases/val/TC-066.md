# TC-VAL-066 (TC-066): Kiểm tra Input Validation khi trường để trống trong phép toán số học

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Negative, Validation, Error Guessing / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | (để trống) |
| Second number | 10 |
| Operation | Add |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Để trống First number.
4. Nhập 10 vào Second number.
5. Chọn Operation = Add.
6. Nhấn Calculate.

## Expected result
Cần xác nhận requirement: Hệ thống Prototype coi chuỗi rỗng là 0 và tính ra 10 (do isNaN('') === false). Kỳ vọng chuẩn là báo lỗi yêu cầu nhập số.
