# TC-VAL-061 (TC-061): Kiểm tra Input Validation khi First number là chữ cái

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Negative, Validation / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | abc |
| Second number | 10 |
| Operation | Add |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập abc vào First number.
4. Nhập 10 vào Second number.
5. Chọn Operation = Add.
6. Nhấn Calculate.

## Expected result
Hiển thị thông báo lỗi màu đỏ: 'Number 1 is not a number'. Không thực hiện tính toán.

## Status / Related bugs
Not Run / None
