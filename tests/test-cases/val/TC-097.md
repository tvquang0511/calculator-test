# TC-VAL-097 (TC-097): Kiểm tra HTML Injection

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Security

## Preconditions
- Basic Calculator page is accessible.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | <h1>5</h1> |
| Second number | 3 |
| Operation | Add |
| Integers only | Unchecked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập `<h1>5</h1>` vào First number.
4. Nhập `3` vào Second number.
5. Chọn Operation = Add.
6. Tích/Bỏ tích Integers only: Unchecked.
7. Nhấn Calculate.

## Expected result
Hiển thị lỗi, không render HTML trên giao diện
