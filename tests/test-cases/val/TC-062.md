# TC-VAL-062 (TC-062): Kiểm tra Input Validation khi Second number là chữ cái

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Negative, Validation / High Priority

## Preconditions
- User is on the Basic Calculator page.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 25 |
| Second number | xyz |
| Operation | Add |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập 25 vào First number.
4. Nhập xyz vào Second number.
5. Chọn Operation = Add.
6. Nhấn Calculate.

## Expected result
Hiển thị thông báo lỗi màu đỏ: 'Number 2 is not a number'. Không thực hiện tính toán.

## Status / Related bugs
Not Run / None
