# TC-VAL-095 (TC-095): Kiểm tra số dạng khoa học

## Requirement ID
FR-VAL-01

## Module / Test type / Technique
Val / Edge

## Preconditions
- Basic Calculator page is accessible.

## Test data
| Trường dữ liệu | Giá trị |
| --- | --- |
| First number | 1e3 |
| Second number | 5 |
| Operation | Add |
| Integers only | Unchecked |
| Build | Prototype |

## Test steps
1. Mở trang Basic Calculator.
2. Chọn Build = Prototype.
3. Nhập `1e3` vào First number.
4. Nhập `5` vào Second number.
5. Chọn Operation = Add.
6. Tích/Bỏ tích Integers only: Unchecked.
7. Nhấn Calculate.

## Expected result
Xử lý được thành 1005 hoặc báo lỗi hợp lệ
